Custom Solana wallet addresses. Generated in your browser. Nothing leaves your machine.

>

100% Client-Side

All keypairs generated in your browser with Web Workers. Private keys never touch a server.

Multi-Threaded

Parallel Web Workers across all CPU cores. Maximum grinding speed from your own hardware.

Zero Network

No API calls. No analytics. No cookies. No tracking. CSP blocks all outbound connections.

Memory Zeroing

Raw secret key bytes wiped immediately after encoding. Non-matching keys destroyed on every cycle.

Auto-Redact

Keys removed from screen after 2 minutes. Clipboard auto-clears 60 seconds after copying.

Auditable

One runtime dependency: @noble/curves, a widely audited ed25519 library. Zero innerHTML — no XSS surface.

How It Works

1

Choose your pattern

Pick the text you want in your Solana address using the Base58 alphabet.

2

Pick the position

Prefix (start), suffix (end), or anywhere in the address.

3

Grind

Your CPU generates thousands of keypairs per second until it finds a match.

4

Save your key

Copy your private key and store it securely. It auto-redacts from the screen.
