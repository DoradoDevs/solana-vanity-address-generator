After the page loads you can turn the network off. Grinding does not phone home. Stop with the button, Esc, or Ctrl+C.

100% client-side

Every keypair is generated in your browser. The host only delivered this static page. It has no account system and no API that could receive a key.

Multi-core workers

The search runs in Web Workers, one per core you allow, so the tab can use the machine you already have. The rain animation pauses while they grind.

Zero network

Content-Security-Policy sets connect-src 'none'. That blocks fetch, XHR, websockets, and beacons. No web fonts, cookies, or analytics are loaded.

Memory wiping

Seed bytes are cleared after each attempt. The key on screen is removed when the terminal clears, about 60 seconds after a match, and redacts itself after two minutes if it is still showing.

Clipboard hygiene

Click the private key to copy it. About 60 seconds later the page tries to clear the clipboard if that same key is still on it. A public tip address is not cleared.

Small dependency

Key derivation uses @noble/curves ed25519. The page is built from text nodes, not HTML strings, so a pattern cannot become markup.

What a Solana vanity address is

A normal keypair, kept only if the public address contains the text you asked for.

A Solana address is the Base58 spelling of an ed25519 public key. Vanity grinding creates ordinary keypairs with the browser's cryptographic random source and discards the ones that miss. The pattern is a filter on the address you can already see. It does not weaken the private key, and it does not require a server to "reserve" anything.

You choose where the text sits. A suffix (the end) is the usual choice. Anywhere is faster because the text can land in many slots. A prefix is harsher: most addresses are 44 characters and start with 2–9, A–H, or J. A prefix like sol starts with a rare letter, so …sol finishes long before sol….

Base58 leaves out 0, O, I, and l so those glyphs cannot be confused. Each extra case-sensitive character multiplies the work by about 58. A letter you allow in either case multiplies it by about 29 instead. Digits have no second case, so "ignore case" does not speed them up.

How a run works

1

Choose the text

Type a short Base58 pattern. The estimator below turns that length into an expected number of keys and a rough time.

2

Pick the slot

Prefix, suffix, either end, or anywhere. Case-sensitive is optional and slower for letters.

3

Grind locally

Workers derive public keys with @noble/curves until one address matches. The ETA updates from the rate your machine actually hits.

4

Save the key offline

The private key is the 64-byte Solana secret (seed plus public key), Base58-encoded, which wallets import. Copy it into a password manager or hardware wallet. Closing the tab discards it.

Safety FAQ

What this page can and cannot see.

Do private keys leave the browser?

No. Workers generate keypairs on your device and post the match back to this page. The production Content-Security-Policy is connect-src 'none', which blocks fetch, XHR, websockets, and beacons. There is no account and no backend that could store a key. Server logs can show that someone loaded the static files, the same as any website, and they do not include the pattern or the key.

What should I save, and when does it disappear?

Save the address and the private key before you close the tab. The private key is 64 bytes — the 32-byte seed followed by the public key — written in Base58, which is the form Solana wallets import. About 60 seconds after the run finishes, the terminal wipes itself. A key line that is still visible redacts after two minutes. If you copied the key, the page tries to clear the clipboard about 60 seconds later when the browser allows a clipboard read.

Is a vanity key weaker than a normal Solana key?

No. It is a normal ed25519 keypair from crypto.getRandomValues. The search only keeps a public address that happens to contain your text. A short pattern is easy to find and just as strong as any other fresh key. Treat the private key like cash: anyone who has it controls the wallet. For a high-value address, run the page offline, then move the key to a hardware wallet or a password manager. Never paste it into a website, including this one.

Why can a prefix take so much longer?

About 94% of Solana addresses are 44 characters, and those start with 2–9, A–H, or J. A first character outside that set is roughly 17× rarer than a common one. 1 is uncommon. Lowercase and letters after J are rare. Suffix and anywhere avoid that bias. The estimator states which case you are in before you start.

Which characters are allowed?

Base58: digits 1–9, uppercase A–H, J–N, P–Z, and lowercase a–k, m–z. Zero, capital o, capital i, and lowercase L are excluded because they look like each other.

Do you use analytics, cookies, or a wallet extension?

No analytics, no cookies, no wallet adapter, and no web fonts. The page does not ask for a Solana provider and does not build a transaction. Optional tips are a public address you copy into a wallet you already use.

What does the tip line do?

If the operator has published a public Solana address, you can copy it and send SOL from your own wallet. This page does not open a wallet, set an amount, or learn whether you paid. If the address is blank, tips are off. A placeholder is not shown, so funds cannot go to an address nobody controls on purpose.

What is Pro?

Pro is a feature flag in the site config, not a checkout. Off, which is the default, every run looks for one address, and patterns longer than five characters show a notice. On, the terminal can collect several matches in one run. Either way the keys stay in the tab. There is no card form and no payment API key in this project.

How do I know this deploy was not tampered with?

Use vanitygrinder.com, or a copy you built yourself from the public source. After load, open DevTools and confirm the Content-Security-Policy includes connect-src 'none'. Then start a short grind and confirm the network panel stays empty. A lookalike can remove those rules. This page will never ask you to paste a private key back in.
