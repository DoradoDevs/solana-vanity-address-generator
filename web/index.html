    What stays on your device

    Everything but the payment. The host delivered this static page; it has no account system and no API that could receive a key.

    • Keys made here

      Every keypair is generated in your browser, in Web Workers, one per core you allow, so the tab can use the machine you already have.

      Web Workers, @noble/curves ed25519

    • Payment is the only call

      Content-Security-Policy lets this page connect only back to this site, for the $1 USDC payment. Fonts are served from this site; nothing is loaded from another host. No cookies or analytics. The grind worker is served with a policy that allows no connections at all, and it never receives the RPC URL.

      worker: default-src 'none'

    • Wiped after use

      Seed bytes are cleared after each attempt. A matched key stays hidden until you reveal it. The terminal clears about 60 seconds after that, and a key line that is still showing redacts itself after two minutes. About 60 seconds after you copy the key, the page tries to clear the clipboard if that same key is still on it. A public tip address is not cleared.

      clears 60 s after reveal

    • Small dependency

      Key derivation uses @noble/curves ed25519. The page is built from text nodes, not HTML strings, so a pattern cannot become markup.

    What a Solana vanity address is

    A normal keypair, kept only if the public address contains the text you asked for.

    A Solana address is the Base58 spelling of an ed25519 public key. Vanity grinding creates ordinary keypairs with the browser's cryptographic random source and discards the ones that miss. The pattern is a filter on the address you can already see. It does not weaken the private key, and it does not require a server to "reserve" anything.

    You choose where the text sits. A suffix (the end) is the usual choice. Anywhere is faster because the text can land in many slots. A prefix is harsher: most addresses are 44 characters and start with 2–9, A–H, or J. A prefix like pump starts with a rare letter, so …pump finishes long before pump….

    Base58 leaves out 0, O, I, and l so those glyphs cannot be confused. Each extra case-sensitive character multiplies the work by about 58. A letter you allow in either case multiplies it by about 29 instead. Digits have no second case, so "ignore case" does not speed them up.

    How a run works

    1. Choose the text

      Type a short Base58 pattern. The generator shows the odds as you type, and the estimator below turns a length into an expected number of keys and a rough time.

    2. Pick the slot

      Prefix, suffix, either end, or anywhere. Case-sensitive is optional and slower for letters.

    3. Grind locally

      Workers derive public keys with @noble/curves until one address matches. The figures update from the rate your machine actually hits.

    4. Save the key offline

      The private key is the 64-byte Solana secret (seed plus public key), Base58-encoded, which wallets import. Copy it into a password manager or hardware wallet. Closing the tab discards it.

    Safety FAQ

    What this page can and cannot see.

    Do private keys leave the browser?

    No. Workers generate keypairs on your device and post the match back to this page. Keys are generated on your device; the only network call is payment verification. Those calls go to this site's own functions and carry your paying wallet's public address and a one-time code for the payment, never the pattern or the private key. The grind worker cannot open a connection: the browser enforces that.

    What should I save, and when does it disappear?

    Save the address and the private key before you close the tab. The private key is 64 bytes — the 32-byte seed followed by the public key — written in Base58, which is the form Solana wallets import. The key stays hidden until you click to reveal it, so a grind that finishes while you are away waits for you. About 60 seconds after you reveal it, the terminal wipes itself. A key line that is still visible redacts after two minutes. If you copied the key, the page tries to clear the clipboard about 60 seconds later when the browser allows a clipboard read.

    Is a vanity key weaker than a normal Solana key?

    No. It is a normal ed25519 keypair from crypto.getRandomValues. The search only keeps a public address that happens to contain your text. A short pattern is easy to find and just as strong as any other fresh key. Treat the private key like cash: anyone who has it controls the wallet. For a high-value address, run the page offline, then move the key to a hardware wallet or a password manager. Never paste it into a website, including this one.

    Why can a prefix take so much longer?

    About 94% of Solana addresses are 44 characters, and those start with 2–9, A–H, or J. A first character outside that set is roughly 59× rarer than a common one. 1 and J are uncommon. Lowercase and letters after J are rare. Suffix and anywhere avoid that bias. The generator and the estimator state which case you are in before you start.

    Which characters are allowed?

    Base58: digits 1–9, uppercase A–H, J–N, P–Z, and lowercase a–k, m–z. Zero, capital o, capital i, and lowercase L are excluded because they look like each other.

    Do you use analytics, cookies, or a wallet extension?

    No analytics and no cookies. Fonts are served from this site; nothing is loaded from another host. The $1 grind payment connects a Solana wallet through the Wallet Standard — Phantom, Solflare, Backpack, and others — and asks it to sign a transfer of exactly 1.00 USDC. That is the only transaction this page builds. The grind does not use that wallet, and the new private key is still generated on this device. Optional tips are a public address you copy into a wallet you already use.

    What does the tip line do?

    The tip line shows the same public address that receives the grind payment. Copy it into a wallet you already trust if you want to send a tip. The page does not learn whether a tip arrived. The grind payment is $1 in USDC per grind, paid from your wallet, and is checked by the site's own function.

    What is Pro?

    Pro is a feature flag in the site config, not a checkout. Off, which is the default, every run looks for one address, and patterns longer than five characters show a notice. On, the generator can collect several matches in one run. Either way the keys stay in the tab. There is no card form and no payment API key in this project.

    How do I know this deploy was not tampered with?

    Use vanitygrinder.com, or a copy you built yourself from the public source. After load, open DevTools and confirm connect-src is 'self': the page can connect only back to this site. During a grind, the network panel should not add requests. A lookalike can remove those rules. This page will never ask you to paste a private key back in.

    Optional tip and Pro
